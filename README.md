# Hidar (ሕዳር) — Market Price Intelligence

**Know your crop's worth before you leave the farm.**

Hidar is a web-based platform that provides real-time market price data, alerts, and AI-powered forecasts for Ethiopian staple crops. Built for farmers, traders, and cooperatives.

## Features
- 🔍 Real-time price lookup by crop, grade, and market
- 🔔 SMS & web push price alerts
- 📝 Crowdsourced price reporting with rewards
- 📊 7-day price trends
- 🌟 Premium AI forecasts & market recommendations

## Tech Stack
- Frontend: HTML, CSS, JavaScript, Bootstrap 5
- Backend: FastAPI + SQLite (embedded)
- Hosting: GitHub Pages (frontend) + Railway (backend)
- Database: SQLite (file-based, embedded in repo)
