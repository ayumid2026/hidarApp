# Hidar (ሕዳር) — Market Price Intelligence for Ethiopian Farmers & Traders

**Tagline:** *"Know your crop's worth before you leave the farm."*

## Overview
Hidar is a web-based SaaS platform that provides real-time market price data, alerts, and AI-powered forecasts for Ethiopian staple crops. It empowers smallholder farmers and traders to make better selling decisions, reducing information asymmetry and maximizing revenue.

## Features (MVP)
- 🔍 **Price Lookup** — Search prices by crop, grade, and market
- 🔔 **Price Alerts** — Set SMS or web push notifications for price thresholds
- 📝 **Crowdsourced Reporting** — Users submit prices with GPS and photos
- 📊 **Trend Charts** — 7-day price trends (coming soon)
- 🌟 **Premium Insights** — AI-powered 7-day forecasts and market recommendations (coming soon)

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Hosting:** GitHub Pages (free)
- **Backend (planned):** Python FastAPI, PostgreSQL
- **SMS:** Africa's Talking API
- **Payments:** Telebirr Merchant API
